# Project Management Frontend

This frontend is now a Vite React application.

## Setup

1. Open a terminal in `frontend`
2. Run `npm install`
3. Run `npm run dev`

The app will launch with React and preserve the original login, registration, dashboard, and project board functionality.

## Notes

- API calls use `http://localhost:5000/api`
- Authentication token is stored in `localStorage.token`
- Project selection is stored in `localStorage.projectId`
